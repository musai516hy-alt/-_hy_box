💡 일상 속 비유로 완벽히 이해하는 Git 5대 개념

어려운 개발 용어를 구역 사역과 일상생활의 친숙한 개념으로 풀어드렸습니다.

📸

Commit (커밋)

비유: 게임의 "세이브 포인트" 또는 "사진 스냅샷"

"오늘 목양 수첩 출석 체크 기능 완성!"처럼 중요한 작업을 마칠 때마다 사진을 찍어두는 것입니다. 언제든 버그가 생기면 그 시점의 과거로 되돌아갈 수 있습니다.

📦

Staging Area (스테이징)

비유: 택배 상자에 포장할 물건을 담는 과정 (`git add`)

책상에 파일 10개가 있더라도, 이번에 저장하고 싶은 파일만 골라서 상자에 쏙 담는 과정입니다. 준비된 파일만 깔끔하게 커밋할 수 있습니다.

🌿

Branch (브랜치)

비유: 원본을 건드리지 않는 "평행 세계 실험실"

기존의 안전한 목양 수첩을 그대로 둔 채, "새로운 성경 통독 표 기능"을 마음껏 실험해볼 수 있는 복사본 가지(Branch)입니다. 마음에 안 들면 가지째 버리면 그만입니다.

☁️

GitHub & Push (깃허브와 푸시)

비유: 화재나 분실에도 안전한 "구글 드라이브 원격 금고"

Git이 내 컴퓨터 안의 기록 장치라면, GitHub는 인터넷 세상에 안전하게 보관해두는 온라인 백업 금고입니다. `git push`로 내 컴퓨터의 기록을 클라우드에 올려둡니다.

🛡️

.gitignore (비밀 가림막)

비유: 외부에 공개하면 안 되는 비밀 일기장 가리기

API 키나 비밀번호가 적힌 `.env` 파일처럼 GitHub에 올리면 안 되는 파일들을 Git이 자동으로 감지하여 인터넷에 올라가지 않도록 막아줍니다.

🔄

Pull (풀)

비유: 최신 내용 다운로드 및 동기화

다른 컴퓨터나 동역자가 GitHub에 올려둔 최신 작업 내역을 내 컴퓨터로 쏙 가져와 동기화하는 명령어입니다.

🚀 혜영 님의 컴퓨터에서 바로 써먹는 5분 실전 루틴

터미널(PowerShell 또는 VS Code)을 열고 딱 이 순서대로만 진행해 보세요.

1

[최초 1회만] 내 이름과 이메일 등록하기

Git에게 "내가 이 작업을 기록하는 사람이다"라고 알려주는 과정입니다.

git config --global user.name "손혜영"
git config --global user.email "내이메일@gmail.com"
2

[폴더당 1회] 내 프로젝트 폴더에 Git 시작하기

현재 작업 폴더(예: `c:\class\언약교회구역모임`)를 Git 타임머신 관리 대상으로 지정합니다.

git init
3

[일상 루틴 1] 변경된 파일 상자에 담기

수정한 파일 전체를 커밋 대기 상자(Staging Area)에 올립니다.

git add .
4

[일상 루틴 2] 세이브 포인트 만들기 (커밋)

어떤 작업을 했는지 한 줄 요약 메시지와 함께 기록을 봉인합니다.

git commit -m "목양 수첩 성경 말씀 데이터 추가 완료"
5

[일상 루틴 3] GitHub 원격 금고로 안전하게 전송하기

내 컴퓨터가 고장 나도 끄떡없도록 GitHub 클라우드에 최종 업로드합니다.

git push origin main
🚨 당황하지 않는 긴급 복구 & 상황별 치트시트

실수를 했거나 문제가 생겼을 때 바로 복사해서 해결하는 비상 처방전입니다.

내가 처한 상황 해결 명령어 설명
지금 내 상태가 궁금할 때 git status 어떤 파일이 수정되었고 어떤 파일이 담겼는지 확인
지난 커밋 기록들을 보고 싶을 때 git log --oneline 과거에 기록한 세이브 포인트 목록을 한 줄씩 깔끔하게 열람
수정하다가 망쳐서 원본으로 되돌리고 싶을 때 git restore . 아직 커밋하지 않은 모든 수정을 취소하고 마지막 저장 상태로 복구
방금 쓴 커밋 메시지를 고치고 싶을 때 git commit --amend -m "새로운 메시지" 마지막 커밋의 설명 문구를 덮어써서 수정
GitHub에서 최신 코드 내려받고 싶을 때 git pull origin main 클라우드에 있는 최신 변경 사항을 내 컴퓨터로 동기화
